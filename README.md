## 🎯 What it Calculates

1. **Monthly Token Spend**:
   - Compares **GPT-4o**, **Claude 3.7 Sonnet**, **DeepSeek V3 / R1**, **Google Gemini 2.0 Flash**, and **Llama 3.3 70B**.
   - Factor in prompt cache hit discounts (50% to 90% input cost reduction).
2. **Self-Hosted GPU Hardware Sizing (VRAM)**:
   - Sizing calculations for **FP16 / BF16** unquantized weights (~2GB per 1B parameters).
   - Optimized sizing for **FP8** and **4-bit AWQ / GPTQ** quantization profiles.
   - Recommended GPU cluster mapping across **NVIDIA H100 (80GB)**, **A100 (40GB/80GB)**, and **L40S**.
